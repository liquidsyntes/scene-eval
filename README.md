# Scene Eval — Приложение для самооценки перформанса

**Scene Eval** — это веб-приложение, созданное для артистов, исполнителей и перформеров. Оно помогает структурировано анализировать свои выступления, фиксировать сильные и слабые моменты, оценивать уровень безопасности и взаимодействия с аудиторией, а также планировать улучшения для будущих сцен.

## ✨ Основные возможности

* **Структурированная форма оценки**: Процесс разбора разделен на 7 логических блоков:
  1. Общие данные (название, дата, формат)
  2. Безопасность и согласие (лимиты, aftercare)
  3. Драматургия и структура
  4. Сценическое исполнение (тело, пространство, контакт)
  5. Визуал, реквизит и техника
  6. Реакция зала и обратная связь
  7. Выводы и план на будущее
* **Автосохранение черновика**: Ты не потеряешь свои мысли, если случайно закроешь вкладку — приложение автоматически сохраняет данные в черновик.
* **История выступлений**: Просмотр списка всех сохраненных оценок с краткой сводкой.
* **Экспорт данных**: Возможность выгрузить любой разбор в форматах `JSON` или удобном читаемом `Markdown` для дальнейшего использования или публикации.
* **Адаптивный дизайн**: Удобно заполнять форму как с компьютера, так и с мобильного телефона сразу после выступления.

## 🛠 Стек технологий

* **Frontend**: React, TypeScript, Vite, Tailwind CSS
* **UI Компоненты**: shadcn/ui, Radix UI, Lucide Icons
* **Роутинг и Состояние**: wouter, React Query (@tanstack/react-query)
* **Backend**: Node.js, Express
* **Хранение данных**: Локальная файловая система (JSON-файлы в директории `data/`)
* **Валидация и Схемы**: Zod, Drizzle ORM schema
